# Interactive 3D Website

Vite + TypeScript + React Three Fiber scaffold for the Hermes 7-agent team.

See [TEAM.md](./TEAM.md) for profiles, models, and the supervisor workflow. See [AGENTS.md](./AGENTS.md) for coding rules the agents follow.

```bash
npm install
npm run dev
```

Drag to orbit the hero mesh. Production path: `npm run build` then Vercel/Netlify via the `qa-deployer` profile.
